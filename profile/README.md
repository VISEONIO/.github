# VISEON

**Semantic Intelligence** · Discover | Discuss | Transact

VISEON is a Semantic Control Plane (operating system for AI) for governing organisational meaning and evidence across enterprise systems, websites and AI interfaces. AI agents can't execute on canonical truth until you define it.

**Canonical source: [viseon.io](https://viseon.io).** This organisation holds public reference material only.

## Four solutions, all live

- [VISEON for Web](https://viseon.io/viseon-for-web/): Semantic Entity Optimisation (SEO 3.0) and an MCP server for your website.
- [VISEON for Enterprise](https://viseon.io/viseon-for-enterprise/): a governed Semantic Control Plane over your existing systems.
- [VISEON for Qlik (vCat)](https://viseon.io/viseon-for-qlik-vcat/): governed meaning for your Qlik analytics estate.
- [VISEON Data Assurance](https://viseon.io/viseon-data-assurance/): every row scored where it lives, with evidence.

[Smarter.SEO](https://www.differentia.consulting/smarter.bi/solutions/smarter-seo-powered-by-qlik/) is VISEON.IO for Qlik customers, delivered by Differentia Consulting.
